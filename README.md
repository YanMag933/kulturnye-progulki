# Культурные прогулки по Москве

PWA: создать квест и гулять по Москве.

## Открыть

После деплоя: `https://yanmag933.github.io/kulturnye-progulki/`

Локально: откройте `index.html` или `ОТКРЫТЬ.bat`.

## Кнопки

- **Создать** — конструктор механик  
- **Гулять** — прохождение на телефоне  

## Почему GitHub, не Google Таблицы

Хостинг игры — статический сайт (HTML/JS/CSS/PWA). Таблицы удобны для базы контента, но не заменяют приложение.
